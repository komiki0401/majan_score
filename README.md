# 雀録 / JANROKU

React + TypeScript の麻雀スコア管理プロトタイプ（第1段階）。ローカルモードは外部サービス不要です。端末間のリアルタイム共有にはSupabaseの接続設定が必要です。

## 起動

Node.js 24 / npm 11 を使用。

```sh
npm ci
npm run dev
```

参加者タブで4人以上を登録 → スコア入力 → 結果確認 → 保存。ダッシュボードから累計成績・個人成績、対局履歴から修正履歴を確認できます。CSVはUTF-8 BOM付きでスプレッドシート向けに出力します。

```sh
npm test
npm run build
npm run preview
```

## 仮ルール

25,000点持ち・30,000点返し、ウマ +20/+10/−10/−20、オカ20ptを1位へ。同点は該当順位のウマ・オカを平均し、同順位（最上位の順位）として集計。すべてルール設定から変更できます。入力順優先も選択可能です。端数は小数第4位まで保持、または整数四捨五入・切り下げを選択。合計点の不一致は保存できません。供託等はプレイヤーへの精算後に入力してください。ルール変更は過去の成績へ遡及しません。編集は記録時ルールを使い、編集前の結果とルールを保存します。

## データと安全性

ローカルモードのデータはこのブラウザのlocalStorageにのみ保存されます。ローカル記録の端末間共有はなく、ブラウザデータ削除で失われます。設定から共有グループを作成すると、認証済み参加者でクラウド保存・リアルタイム共有ができます。CSVは閲覧用のバックアップで、再インポートは未実装です。ローカル段階にはログイン・主催者権限・改ざん防止・サーバー検証はありません。この端末を操作できる人はデータを変更できます。機密データの登録は避けてください。

`domain.ts` に計算・モデル・Repositoryインターフェースを分離しています。`cloud.ts` と `CloudSettings.tsx` でSupabaseのログイン、共有グループ、招待、楽観的ロックとリアルタイム購読を実装しています。DBの設定は `supabase/setup.sql`。詳しい導入手順は [共有機能のセットアップ](supabase/README.md) を参照してください。現時点では一つの対局グループを管理し、卓番号で結果を区別します。特殊ルール・複数大会切り替え・PWAオフラインキャッシュは今後の拡張です。

## 公開

GitHub の Settings → Pages → Source を GitHub Actions に設定してください。main への push 時にテスト・型チェック・ビルド後にデプロイします。相対baseなのでリポジトリ配下でも利用できます。GitHub Pages の HTTPS を使用してください。設定しただけでは公開されず、実際のpushとActions成功が必要です。秘密情報は不要で、ソースに含めないでください。

## ポイントの直接入力

スコア入力の「点数で入力 / ポイントで入力」で切り替えます。ポイント入力では今回の半荘の計算済みポイントを入力し、そのまま累計へ加算します（累計そのものの入力ではありません）。ウマ・オカ・端数処理は再適用しません。小数第4位までの正負の値と0に対応。ルールによってポイント順と順位が異なるため、順位は別途選択します。同順位は設定ルールに従い、例として1位・1位・3位・4位を指定します。

持ち点を逆算して捏造せず、履歴では「持ち点未入力」、CSVの持ち点列は空欄として保存・出力します。従来の保存データは引き続き読み込めます。編集時には元の入力方式を復元し、修正前のデータを履歴に残します。

## 日別ダッシュボード

累計ランキングをダッシュボードの先頭に表示します。「集計対象」の対局日ボタン・カレンダーから5/5、6/7などを切り替えると、その日だけのランキング、個人成績、対局数、履歴、CSVへ揃えて表示します。「全期間」で従来の全対局集計へ戻せます。初期表示は最新の対局日（記録がない場合は今日）です。

新規入力には選択中の対局日を引き継ぎます（全期間選択時は今日）。対局日は入力画面で指定・修正でき、日付を変更した場合も以前の日付を修正履歴に残します。半荘番号は対局日単位です。過去データの対局日は記録日時をブラウザの現地日付に変換して扱い、修正するまでは保存データを書き換えません。CSVには対局日列も追加します。ルールの確認・変更は「設定」タブにまとめています。

## ポイント推移と履歴一覧

ダッシュボードには、最近の対局一覧に代えてプレイヤー別の順位折れ線を表示します。名前で一人に絞り込み、対局選択で各半荘の確定順位を確認できます。縦軸は上から1位〜4位、横軸は半荘の記録順（全期間では対局日順、同日は記録順）です。同順位は同じ高さに表示し、未参加の半荘は線をつなぎません。

対局履歴の先頭には、名前を列・半荘を行にしたポイント一覧表を追加しました。最終行に選択期間の累計、未参加には「—」を表示します。対局行のリンクから編集できます。参加者が多い場合は表を横スクロールできます。従来の詳細・修正履歴も下に残しています。

対局履歴の詳細カードには削除ボタンもあります。確認ダイアログで対局日・卓・参加者・ポイントを確認したうえで削除します。対局とその修正履歴は元に戻せません。削除すると、ランキング・グラフ・一覧表・CSVの集計から除かれます。

## 設定から日付別に記録を管理

「設定」の先頭で、カレンダーまたは記録日の選択欄から対象日を指定できます。対局ごとの編集、その日の履歴への移動、対象日だけのCSV出力、全卓を含めたその日全体の一括削除に対応します。一括削除は対象日・件数を確認してから行い、ほかの日の記録は残します。修正履歴も削除され、元には戻せません。

スコア入力には東・南・西・北の表示を置かず、自由な順で参加者を選択できます。同点時に入力順優先を選んだ場合は上から順に扱います。
